# **Dev Glow Portfolio**

Act as a **Senior Frontend Developer, UI/UX Designer, and Professional Portfolio Designer**.

I need you to create a **fully developed, modern, interactive, and professional personal portfolio website** for my personal and career purposes.

The portfolio must have a **premium dark theme**, clean visual hierarchy, smooth animations, responsive design, and a professional appearance suitable for recruiters, companies, and professional networking.

## 1. Hero Section

* Display **my name prominently at the top of the page**.

* Keep my name **perfectly centered**.

* Add a short professional tagline below my name.

* Include a modern navigation bar linking to all major sections.

* Add subtle entrance animations.

* Make the hero section visually impressive while keeping it professional.

* Use a dark background with suitable accent colors, gradients, glow effects, or other modern elements.

## 2. Dark Theme

The entire website must follow a **consistent premium dark theme**.

Design requirements:

* Use dark backgrounds throughout the website.

* Use high-contrast but comfortable text colors.

* Use one or two professional accent colors.

* Add subtle gradients and glow effects where appropriate.

* Use glassmorphism or modern dark UI elements where they improve the design.

* Cards should have a dark, slightly contrasting background.

* Buttons should have attractive hover and active states.

* Avoid excessive brightness, excessive colors, or distracting effects.

* Ensure excellent readability and accessibility.

* The overall appearance should feel like a **premium modern developer portfolio**, not a basic template.

## 3. About Me

Create a dedicated **About Me** section.

* Keep the main description approximately **4–5 lines**.

* Make it professional and engaging.

* Highlight my personality, technical interests, career goals, and strengths.

* Use a visually attractive layout suitable for the dark theme.

## 4. Skills

Create a dedicated **Skills** section.

* Clearly display my technical and professional skills.

* Position the skills toward the **right side of the layout where appropriate**.

* Maintain proper alignment and responsiveness.

* Highlight the areas where I am strongest.

* Use modern skill cards, badges, progress indicators, animated icons, or other suitable UI elements.

* Add subtle hover animations.

## 5. Education

Create a professional **Education** section.

* Display my educational qualifications clearly.

* Use a modern timeline or card-based design.

* Include:

  * Degree/Course

  * Institution

  * Year/Duration

  * Relevant information

## 6. Experience

Create an **Experience** section.

Include:

* Internships

* Work experience

* Technical roles

* Responsibilities

* Achievements

Highlight the areas where I have demonstrated strong skills and experience.

Use a modern timeline or card-based layout with subtle animations.

## 7. Projects

Create a dedicated **Projects** section.

Showcase my important academic, personal, and technical projects.

For each project include:

* Project title

* Short description

* Technologies used

* Key features

* GitHub/project link

Use interactive project cards with attractive hover effects.

## 8. Contact

Create a professional **Contact** section.

Include:

* Email

* Phone

* LinkedIn

* GitHub

* Other relevant professional links

Add a modern contact form if appropriate.

Make the contact section visually consistent with the dark theme.

## 9. Animations & Interactions

Add modern but professional interactions such as:

* Smooth scrolling

* Fade-in animations

* Scroll reveal effects

* Hover animations

* Interactive cards

* Animated buttons

* Subtle text animations

* Mouse-following or cursor effects where appropriate

* Elegant background particles or ambient effects

Animations must be **smooth and lightweight** and should never reduce usability or readability.

## 10. Responsive Design

The website must be fully responsive for:

* Desktop

* Laptop

* Tablet

* Mobile

Make sure:

* The centered name remains properly aligned.

* The Skills section does not break the layout on smaller screens.

* Navigation adapts properly on mobile.

* Cards resize correctly.

* Text remains readable.

* Animations work smoothly across screen sizes.

## 11. Technical Requirements

Use:

* HTML5

* CSS3

* JavaScript

* Bootstrap where useful

Keep the code:

* Clean

* Well structured

* Easy to customize

* Properly commented

* Optimized for performance

If external libraries are required, include them through appropriate CDN links.

## 12. Personal Information

Do **not** invent important personal information about me.

If my details are not provided, use clearly identifiable placeholders:

* `[YOUR NAME]`

* `[YOUR TAGLINE]`

* `[YOUR EMAIL]`

* `[YOUR PHONE]`

* `[YOUR COLLEGE]`

* `[YOUR DEGREE]`

* `[YOUR SKILLS]`

* `[YOUR EXPERIENCE]`

* `[YOUR PROJECTS]`

* `[YOUR GITHUB]`

* `[YOUR LINKEDIN]`

Make all placeholders easy to find and replace.

## 13. Output

Provide the **complete, ready-to-run portfolio code**.

Do not provide only a design explanation, sample code, or partial implementation.

The final result should be a **fully functional portfolio website** that I can directly run in a browser.

## 14. Quality Check

Before providing the final code, verify that:

1. The entire website follows a consistent **dark theme**.

2. My name is centered correctly at the top.

3. The design looks premium and professional.

4. About Me contains approximately 4–5 lines.

5. Skills are clearly displayed and positioned appropriately.

6. Education, Experience, Projects, and Contact sections are included.

7. All navigation links work correctly.

8. Hover effects and animations work properly.

9. The website is responsive on desktop, tablet, and mobile.

10. Text has sufficient contrast against the dark background.

11. There are no obvious HTML, CSS, or JavaScript errors.

12. The code is complete and ready to run.

13. The final design looks suitable for **professional recruiters and companies**.

### Overall Design Direction

Think of the portfolio as a **premium dark-themed developer portfolio** with a futuristic but professional appearance.

Use:

**Dark UI + elegant accent colors + glassmorphism + subtle glow + smooth animations + interactive cards + clean typography + strong visual hierarchy.**

Avoid:

**clutter, excessive colors, excessive animations, childish design, poor contrast, and generic template-like layouts.**
